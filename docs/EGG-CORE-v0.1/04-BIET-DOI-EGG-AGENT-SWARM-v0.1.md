# BIỆT ĐỘI — EGG AGENT SWARM v0.1

> CANONICAL — 2026-10-03
> Short canonical name: **BIỆT ĐỘI**
> Role: EGG Workforce Layer
> Parent: MỌC CÁNH 2

## Definition

BIỆT ĐỘI is EGG's dynamically assembled, policy-governed workforce of specialized AI workers.

It is NOT simply "many agents running together".

Core rule:

**Contract → Authority → Evidence → Acceptance → Delivery**

## Canonical position

BIỆT ĐỘI does not own EGG Control Plane or Founder authority.

## 20-step absorption roadmap

01. Agent Swarm Constitution — laws and boundaries.
02. Worker Capability Contract — capability, input, output, authority, cost, latency, reliability.
03. Swarm Mission Contract — objective, output, budget, deadline, evidence, acceptance.
04. Swarm Topology Engine — sequential, parallel, pipeline, hierarchical, debate, competition.
05. Dynamic Swarm Builder — compose workers from ERN per mission.
06. Swarm Allocation Engine — route through Worker Registry + AI Router.
07. Swarm Orchestrator — SPAWN → ASSIGN → EXECUTE → OBSERVE → MERGE → VERIFY → CLOSE.
08. Agent-to-Agent Protocol — structured handoff, not uncontrolled chat.
09. Swarm Memory & Artifact Bus — exchange artifacts/evidence, not full context.
10. Failure & Recovery — RETRY → REPLACE → REASSIGN → ROLLBACK → ESCALATE.
11. Swarm Governance — Policy & Authority Engine controls permissions.
12. Swarm Observability — WHO / WHAT / WHY / COST / TIME / EVIDENCE / RESULT.
13. QA / Red Team — independent verification before acceptance.
14. Decision Plane — System 1 / System 2 / Founder authority routing.
15. Swarm Economics — Accepted Value per Unit of Time/Cost.
16. Auto-Scaling — scale workforce only when mission economics justify it.
17. Competition Engine — multiple solutions when evidence-based comparison is useful.
18. Composition Memory — retain proven workforce recipes by mission type.
19. Benchmark — quality, latency, cost, reliability, evidence, autonomy, value.
20. Autonomous Workforce — Founder gives Value Intent; EGG composes and governs the workforce.

## Hard boundaries

- No swarm without a Value Contract and Mission Contract.
- No agent gets authority merely because it is capable.
- No agent may declare final DONE or DELIVERY by itself.
- Parallelism never bypasses ownership, evidence, Task State Machine or Acceptance Gate.
- Browser is HAND, never BRAIN.
- Founder authority remains final.

## Acceptance target

BIỆT ĐỘI is operationally accepted only when EGG can assemble the right workers for a mission, preserve identity and authority, execute/recover work, produce evidence, pass Acceptance Gate, and return accepted value without Founder micromanagement.
